# مراجع | Maraje3

مراجع تطبيق Expo أصلي لطلاب الجامعات في مصر. ينظم المواد بحسب الجامعة والكلية والفرقة والفصل والمقرر، مع بحث عربي/إنجليزي وحفظ محلي للمواد والتنزيلات.

## ما يعمل في النسخة الأولية

- واجهة عربية RTL بخط Cairo مع تنقل أصلي عبر Expo Router.
- استكشاف الجامعات والكليات والفرق والفصول والمقررات.
- بحث محلي يدعم التطبيع الشائع للحروف العربية، مع بحث عبر API عند توفر الكتالوج المشترك.
- تفاصيل الموارد وشارات واضحة للمحتوى التجريبي.
- حفظ المواد وآخر العناصر المفتوحة على الجهاز.
- تنزيل PDF حقيقي من رابط HTTPS وفتحه عبر تطبيق متاح على الجهاز، وإدارة الملفات المحفوظة.
- واجهة إدارة للجامعات والكليات والفرق والفصول والمقررات والمواد. ترفض واجهة الخادم العملية إذا لم تتوفر صلاحية المسؤول أو تأكيد حقوق التوزيع للمستند المرتبط.
- واجهة API مشتركة ومخطط PostgreSQL للكتالوج.

لا توجد ملفات PDF تجريبية أو روابط تنزيل مختلقة في التطبيق. المواد الأولية الافتراضية أمثلة لتقييم البحث والتنقل فقط، وليست امتحانات أو ملفات جامعية حقيقية.

## التطوير والمعاينة

يشغّل Replit سير عمل Expo المسجل للمشروع. يمكن معاينة التطبيق داخل مساحة العمل أو مسح رمز المعاينة لفتحه في Expo Go. من جذر مساحة العمل، أمر التطوير:

```sh
pnpm --filter @workspace/maraje3 run dev
```

فحص TypeScript:

```sh
pnpm --filter @workspace/maraje3 run typecheck
pnpm --filter @workspace/api-server run typecheck
```

## الكتالوج المشترك وإدارة المسؤول

يستخدم الخادم PostgreSQL المهيأ للمشروع. مزامنة مخطط قاعدة التطوير بعد تعديل مخطط Drizzle:

```sh
pnpm --filter @workspace/db run push
```

إعداد المسؤول اختياري للعرض المحلي. لتمكين واجهة الإدارة، أضف السر `MARAJE3_ADMIN_TOKEN` عبر أسرار المشروع. لا يوجد رمز افتراضي، ولا تُحفظ قيمة الرمز في تطبيق الهاتف. عند غياب السر، ترفض واجهة API عمليات المسؤول.
بعد إضافة السر أو تدويره، أعد تشغيل سير عمل API Server ليقرأ القيمة الجديدة.

الطلاب لا يحتاجون إلى حساب. المحفوظات والتنزيلات وسجل المشاهدة تخزّن محلياً على الجهاز.

لم تُهيأ خدمة تخزين ملفات. لا يدعم التطبيق رفع ملفات عامة في هذه النسخة؛ يمكن للمسؤول حفظ بيانات رابط PDF خارجي آمن بعد تأكيد صلاحية توزيعه. لا يُعرض إجراء فتح أو تنزيل للموارد بلا ملف.

## Android

يتضمن `app.json` اسم التطبيق ورقم الإصدار ومعرّف Android فريداً، ودعم RTL، وأيقونة adaptive، وشاشة بدء. يحتوي `eas.json` على ملف `preview` بصيغة APK وملف `production` بصيغة AAB كما هو مطلوب.

لم يُنشأ APK أو AAB في هذه البيئة. معاينة Expo لا تنتج حزمة Android قابلة للتثبيت، كما أن إنشاء الحزمة يتطلب سير بناء Android معتمد وإعداد الحساب اللازم. لا يعتبر وجود ملفات الإعداد دليلاً على نجاح بناء التطبيق.

## متطلبات قبل إطلاق مكتبة متعددة المستخدمين

- إعداد `MARAJE3_ADMIN_TOKEN` من خلال أسرار Replit.
- إدخال سجلات جامعية حقيقية ومواد مرخّصة من مسؤول معتمد.
- اختيار تخزين مستندات مناسب وإعداده قبل الاعتماد على ملفات خارجية دائمة.
- إنشاء APK/AAB فعلي والتحقق منه في سير بناء Android مناسب قبل التوزيع.
